# Peer Check: One Page
## A second pair of eyes, without a formal audit

**Document Owner:** Data Program Management Lead
**Classification:** Internal, Program Reference
**Version:** 1.0 | **Last Updated:** 2026-11
**Review Cycle:** Annual

> **Purpose:** A small team does not need a second line of defense. It needs one trusted peer who looks at the work before it is used, so the person who owns the data is never the only one who has seen it. Print this page, hand it to your peer, and fill it in together in about 20 minutes.

---

## Who can be the peer

Anyone who did not do the work and will give an honest answer: a colleague, a board member with a spreadsheet habit, a volunteer, or a counterpart at a partner organization. They do not need to be technical.

## The check

The data owner shows the file. The peer reads it and answers each question aloud.

| # | Question | Pass | Notes |
|---|---|---|---|
| 1 | Can you tell what every column means without asking me? | | |
| 2 | Are the states, dates, and phone numbers written one way throughout? | | |
| 3 | Pick five names at random. Is each written the same way everywhere it appears? | | |
| 4 | Is there one master copy of each list, and do you know where it is? | | |
| 5 | Look at the Changes sheet. Can you follow what was changed and why? | | |
| 6 | Is anything deleted that you would want back? | | |
| 7 | Pick the most important number in my report. Can I show you where it comes from? | | |
| 8 | Is there personal information in here that does not need to be? | | |

## Pressure-test the strategy

Before you present a plan or recommendation, ask Claude to run it past a board of advisors and a devil's advocate. This is the same job as the peer check, applied to thinking instead of data: it surfaces blind spots while they are still cheap to fix. Use `Skills_Library/board-of-advisors/SKILL.md` and `Skills_Library/devils-advocate/SKILL.md`. An AI review does not replace the human peer for decisions that affect people. It adds a second look.

## Record the result

Write the date, the peer's name, and what changed because of the check in the Changes sheet. If any answer was "no", fix it and check again.
